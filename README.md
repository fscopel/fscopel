# Fabio Scopel: backend engineer by day, game dev by night

**Senior software engineer in California.** I build backends, web apps, and mobile apps for a living, and games for fun.

I've been pushing code to GitHub since 2011. These days that mostly means C#, TypeScript, and a growing pile of game projects.

---

### 🛠️ What I do

- **Backend & cloud:** .NET / ASP.NET Core APIs, SQL, and cloud infrastructure on Azure and AWS, managed as code with Terraform.
- **Web:** React + TypeScript + Vite, styled with Tailwind.
- **Mobile:** Flutter/Dart.
- **Contracting:** I help teams with architecture decisions, code reviews, and getting products from idea to launch. More at [fscopel.github.io](https://fscopel.github.io).

### 🎮 What I do for fun

I make games under **CoffeeCup Games**. I started with WWII side-scrolling bombers in Unity, then spent time in Godot, and I'm now building in **Unreal Engine 5**.

- 🍉 **Fruit Merge**: a Suika-style 3D fruit-merging puzzle game for Android, built in Unreal Engine 5.
- ✨ **Particle Sandbox**: a small app for playing with particles.
- 🚗 Vehicle physics experiments in Unreal, because driving games are fun to break.

### 🐶 What I tinker with

- [**No Dogs on the Couch**](https://github.com/fscopel/no-dogs-on-the-couch): a Raspberry Pi Zero 2 with a camera and an image model trained in Azure. It catches my dogs on the couch when no humans are around and beeps at them. Dogs are allowed on the couch, just not by themselves.
- **AI in the tools I use:** connecting LLMs to game engines and editors through the Model Context Protocol (MCP).
